# Independent talker Oracle

`talker_oracle.py` decodes the actual component GGUF with upstream `gguf.quants`, runs Transformers `Qwen2Model` with F32 arithmetic/F32 KV, and applies the speech output head. It never imports converter or Rust arithmetic. The tokenizer, tag cleaner and `_need_text` are executed from SHA-pinned official sources; AST extraction excludes vLLM imports. The source model revision is `990d6a74bbf15c1765a6f7736fa839f423fd5b59`, and the tokenizer wrapper belongs to vLLM-Omni `0ea4e3837611325b58f22b7457b039cfeaecf176`.

The complete-text schedule is exact: prefill `[speech SOS] + "You are a helpful assistant.<|endofprompt|>"`; fill feeds five text tokens when available; a final remainder shorter than five repeats the last consumed input before the remainder and TASK. Exactly five remaining text tokens stay in bistream mode until another fill. Forced fill counts include control tokens. Bistream masks every special token except fill; final mode allows only EOS. This does not model a live thinker's starvation timing.

Run on the model host, keeping weights remote:

```sh
PYTHONPATH=/opt/venv/lib/python3.12/site-packages .venv/bin/python \
  -m tools.oracle.sophon_realtime.talker_oracle \
  --model-dir models/Sophon-Realtime-32B-Tag \
  --gguf models/Sophon-Realtime-32B-Tag-GGUF/talker-F32.gguf \
  --text '你好，我是你的语音助手。[laughter]' \
  --rust-trace target/sophon/talker-cpu.jsonl \
  --output target/sophon/talker-oracle-f32 --precision f32 \
  --steps 64 --threads 8 --seed 0
```

The trace must contain one each of `sophon.talker.prompt_ids`, `sophon.talker.text_ids`, and `sophon.talker.sampled_tokens`, with `token_ids`. The latter contains **all** accepted speech/fill/EOS IDs, unlike the externally returned speech-only sequence. There must be one `sophon.talker.logits` record per accepted token, with consecutive `step` values, shape `[6761]` and a readable `binary_path`. Tokenizer IDs and schedule legality are exact checks. `--steps` bounds the compared prefix. An optional `--teacher-tokens` JSON list must agree with the trace if both are supplied; without either input, the Oracle generates masked greedy tokens. Random seeds do not promise cross-framework sampled-token identity.

Before any real Rust comparison, gates are declared to match the existing thinker implementation-error gates: F32 relative RMSE <= 0.001 / cosine >= 0.999999; F16 and BF16 <= 0.005 / >= 0.99998; Q8_0, Q4_0, Q4_1, Q4_K, Q5_K and Q6_K <= 0.03 / >= 0.999. Every compared logits row must meet both thresholds and its allowed/forced greedy ID must match. The report retains max absolute error, RMSE, relative RMSE, cosine, per-step greedy margins and first failing row. Requested precision must match GGUF metadata. These are same-file runtime-error gates, not export-quality or speech-quality acceptance. No threshold is relaxed after failure.

`result.json` records GGUF/source/reference hashes, Torch/Transformers versions, the actual decoder source hash, tensor type counts, all input IDs and per-step metrics. Fresh output directories prevent mixed evidence. No bitwise parity, sampling parity, native FP8, waveform or end-to-end speech quality is implied.

`--activation f32` is the independent dequantized-weight/F32-activation baseline. `--activation runtime` adds independent input QDQ at every native Linear and the functional speech head: F16 inputs round to F16, BF16/F32 inputs remain F32, Q8_0/Q4_0/Q4_1 use Q8_0 inputs, and K weights use signed-scale Q8_K. It reuses the existing independently tested audio/THX activation helper. This is a separate diagnostic; both reports retain the same declared numerical and discrete gates, including any failure. The talker uses F32 KV throughout. Runtime QDQ does not promise identical nonlinear/reduction rounding between PyTorch and Rust.

Validation on 2026-11-11: seven bounded synthetic tests passed locally and on the authorized Linux host (1.642 s remotely). Tests cover independently decoded Q8_0 GGUF weights, full causal prefixes versus cached continuation, repeated final input, exact-five boundary, forced fill, phase controls, trace completeness and tag cleaning. The combined thinker/audio/talker Oracle unit suite passed 20 tests locally. Linux printed existing SWIG deprecation warnings. The real pinned tokenizer entry point was checked read-only; the fixed prompt IDs were `[2610, 525, 264, 10950, 17847, 13, 151646]`, with correct single special IDs for `[laughter]` (151651), `<strong>` (151648), `</strong>` (151649) and `[breath]` (151647).
